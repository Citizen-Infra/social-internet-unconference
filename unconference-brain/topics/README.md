# Topics

Topic files use the stable topic ID as their filename:

`<stable-topic-id>.md`

The initial V1 contract is:

```yaml
---
id: topic-<stable-id>
status: draft
title: A short canonical topic title
bluesky_url:
scheduled_event_id:
merged_from: []
supporter_count: 0
provenance_count: 0
---
```

The body contains the canonical public-safe topic wording. It must not contain
supporter identities or private proposal evidence.
